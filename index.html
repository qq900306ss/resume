Selected incidents

Root cause, or it isn't fixed

Idempotency · distributed delivery

A single signal written 29 times, 703 rows polluted

CauseAn upstream outage triggered at-least-once redelivery while the downstream sync path had zero idempotency.

FixCut the source, SQL window-function dedup cleanup, replayed 75 affected strategies, then made delivery idempotent on (strategy_id, signal_time, status).

Worst case cut from 29× → ~2×.

Concurrency · row locking

SSO logging users out for an hour at a time

CauseToken refresh fired from three unlocked check-then-act sites and clobbered each other — inferred from two rows' contradictory timestamps.

FixAn EnsureFreshToken path with a SELECT FOR UPDATE row lock serializing all three call sites; rejected an optimistic guard on purpose.

Regression test asserts 1 refresh under 4-way concurrency.

Resource leak · storage engine

Pre-market cleanup ran 10 hours, cleared 1 of 189 days

CauseBlind-deleting ~2,900 InfluxDB measurements daily, amplified ~8× by an 8-year backfill, exhausted file descriptors.

FixScan-then-delete — count first, delete only measurements that actually hold data — established as a team operations rule.

Reads are ~10× cheaper than deletes; job stable.

Silent failure · observability

Three hours of alerts, zero trades placed

CauseThe SDK silently ran live strategies in backtest semantics, disabling quantity clamping so every order failed a cash check.

FixEliminated six hypotheses with evidence, fixed mode propagation and made cash handling live-aware.

Live execution restored the same day.
